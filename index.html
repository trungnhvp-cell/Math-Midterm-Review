1Trigonometry

Radian – Degree

π rad = 180° 1 rad = (180/π)° 1° = π/180 rad

Basic values

sin 0 = 0, cos 0 = 1 sin π/6 = 1/2, cos π/6 = √3/2 sin π/4 = √2/2, cos π/4 = √2/2 sin π/3 = √3/2, cos π/3 = 1/2 sin π/2 = 1, cos π/2 = 0

Basic identities

sin²α + cos²α = 1 tan α = sin α / cos α (cos α ≠ 0) cot α = cos α / sin α (sin α ≠ 0) 1 + tan²α = 1/cos²α 1 + cot²α = 1/sin²α

Addition formulas

sin(a ± b) = sin a · cos b ± cos a · sin b cos(a ± b) = cos a · cos b ∓ sin a · sin b tan(a ± b) = (tan a ± tan b) / (1 ∓ tan a · tan b)

Double-angle formulas

sin 2a = 2 sin a · cos a cos 2a = cos²a − sin²a = 2cos²a − 1 = 1 − 2sin²a tan 2a = 2tan a / (1 − tan²a)

Product-to-sum & Sum-to-product

cos a · cos b = ½[cos(a−b) + cos(a+b)] sin a · sin b = ½[cos(a−b) − cos(a+b)] sin a · cos b = ½[sin(a+b) + sin(a−b)] sin u + sin v = 2 sin((u+v)/2) cos((u−v)/2) sin u − sin v = 2 cos((u+v)/2) sin((u−v)/2) cos u + cos v = 2 cos((u+v)/2) cos((u−v)/2) cos u − cos v = −2 sin((u+v)/2) sin((u−v)/2)

Basic trigonometric equations

sin x = m (|m| ≤ 1): x = arcsin m + k2π or x = π − arcsin m + k2π cos x = m (|m| ≤ 1): x = ± arccos m + k2π tan x = m: x = arctan m + kπ cot x = m: x = arccot m + kπ
  • Special cases: sin x = 1 ⇒ x = π/2 + k2π; cos x = 1 ⇒ x = k2π; cos x = 0 ⇒ x = π/2 + kπ.

2Sequences – Arithmetic & Geometric Progressions

Sequence

  • A sequence (uₙ) is a function defined on ℕ*: u(1), u(2), u(3), …
  • Recurrence relation: given u₁ and formula for u_{n+1} in terms of uₙ.

Arithmetic progression (AP)

u_{n+1} = uₙ + d (d = common difference) uₙ = u₁ + (n − 1)d Sₙ = n(u₁ + uₙ)/2 = n[2u₁ + (n − 1)d]/2

Geometric progression (GP)

u_{n+1} = uₙ · q (q = common ratio) uₙ = u₁ · q^{n−1} Sₙ = u₁(1 − qⁿ)/(1 − q) (q ≠ 1) Sₙ = n·u₁ (q = 1) Sum to infinity (|q| < 1): S = u₁ / (1 − q)

3Statistics for Grouped Data

Notation

  • Groups: [a₁; a₂), [a₂; a₃), …, [a_k; a_{k+1}).
  • Frequency of group i: n_i.
  • Midpoint (representative value) of group i: c_i = (a_i + a_{i+1})/2.
  • Sample size: N = n₁ + n₂ + … + n_k.

Mean of grouped data

x̄ = (n₁c₁ + n₂c₂ + … + n_k c_k) / N = (Σ n_i c_i) / N

Median of grouped data

  • Find the group containing position N/2 (median group).
  • Let that group be [a; b) with frequency n_m, cumulative frequency before it C, group width h = b − a.
Mₑ = a + [(N/2 − C) / n_m] · h

Mode of grouped data

  • Identify the group with highest frequency (modal group) [a; b), width h.
  • n_m = frequency of modal group; n_{m−1}, n_{m+1} = frequencies of adjacent groups.
M₀ = a + [(n_m − n_{m−1}) / ((n_m − n_{m−1}) + (n_m − n_{m+1}))] · h

Quartiles (grouped data)

Q₁ uses position N/4; Q₃ uses position 3N/4 Q_p = a + [(pN/4 − C) / n_Q] · h (p = 1, 2, 3)
